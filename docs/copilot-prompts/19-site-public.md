# Prompt 19 — Site public Blade/Livewire

Construis le site public responsive en Blade + Livewire + Tailwind, sans Angular.

Pages :
- accueil ;
- catalogue des offres ;
- détail d'une offre ;
- checkout ;
- consultation sécurisée de commande ;
- FAQ et contact si le contenu existe.

Exigences :
- design moderne, accessible et responsive ;
- données des offres et prix issues de la base ;
- affichage des devises et durées exactes ;
- états chargement/erreur/validation ;
- SEO de base : titres, descriptions, URLs propres ;
- aucune fausse statistique, fausse note ou faux témoignage ;
- ne pas afficher d'offre inactive ;
- protection du checkout et rate limiting.

Respecte le thème actif et les composants existants. N'ajoute pas de dépendance frontend sans justification.
