# Prompt 25 — Documentation et feuille de route

Crée ou actualise la documentation du projet.

Fichiers attendus selon le besoin :
- `docs/ARCHITECTURE.md`
- `docs/DATABASE.md` avec ERD Mermaid ;
- `docs/DEVELOPMENT_ROADMAP.md` ;
- `docs/DEPLOYMENT.md` ;
- `docs/SECURITY.md` ;
- `docs/INTEGRATIONS.md`.

Dans `DEVELOPMENT_ROADMAP.md`, utilise uniquement les statuts :
- NOT_STARTED
- IN_PROGRESS
- BLOCKED
- REVIEW_REQUIRED
- COMPLETED

Ne marque une tâche COMPLETED que si le code existe, les tests pertinents ont été exécutés avec succès et les critères d'acceptation sont satisfaits. Ajoute les commandes réellement exécutées et les dépendances bloquantes.

La documentation doit correspondre au code réel, pas à une architecture imaginée. N'inclus aucun secret, token, mot de passe ou donnée personnelle réelle.
